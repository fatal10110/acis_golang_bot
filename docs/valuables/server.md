# Server and datapack facts

Read on 2026-11-24; every design choice rests on these. Server paths (`internal/gameserver/...`)
refer to [fatal10110/acis_golang](https://github.com/fatal10110/acis_golang). Datapack paths
(`npcs/...`, `spawnlist/...`, `multisell/...`, `items/...`, `buyLists.xml`, `recipes.xml`,
`restartPointAreas.xml`) refer to `aCis_datapack/data/xml`; HTML pages (`html/...`) to
`aCis_datapack/data`. Bot paths name this repository. Nothing the design needs is missing on the
server, so this plan files no server issue.

## Datapack

Drops as the server reads them (`data/xml/npc.go:36-47,127-131`): `<drops><category
type="DROP|SPOIL|HERB|CURRENCY" chance="%"><drop itemid min max chance="%"/>`
(`npcs/20000-20999.xml:209-216` shows SPOIL and CURRENCY). Shipped: 4561 DROP, 1645 SPOIL, 1905
CURRENCY and 7362 HERB categories. Multisell rows name their NPCs, ingredients and productions
(`multisell/002.xml:3-28`); some are upgrades consuming another weapon
(`multisell/311262511.xml:2-12`, the Blacksmith of Mammon: a weapon plus Ancient Adena). Recipes
name their product (`recipes.xml:3`, `product="3-1"`).

## Prices the bot has (M8)

One number per tradable template: the reference price (`items/*.xml` `price`, `datapack/items.go`
`buildPrice`, kept only for `price > 0` and `is_tradable`). An untradable template has none, so it
is never valuable. The price says nothing about scarcity: Scroll: Enchant Weapon (Grade D) (955)
costs 50000 at a supply of 54 per hour, Tears of Eva (309) 136000 at 0.62
([score](score.md#figures)).

| Price | Value | Where |
| --- | --- | --- |
| NPC buy-back | 50 % of reference | `network/serverpackets/shop_trade.go:121` |
| Bot store (loot) | 60-75 % of reference (120-150 % of buy-back) | bot `store.go` `defaultStorePolicy`, `storePrice` |
| Most a bot pays at a player store | 150 % (`Market.MaxOverReference`), never above a spawned NPC's price | bot `market.go` `defaultMarketPolicy` |
| NPC buylist (NPC id above 0, spawned or not; `npcId="-1"` lists not counted) | the cheapest buylist price; such an item is never loot | bot `shop.go` `indexShops`, `travel.go` `cheapest`, `store.go` `storeLoot` |

The valuables band sits between the store's top (75 %) and the market cap (150 %), so a released
valuable in a bot store is something another bot's market errand may buy as gear.
